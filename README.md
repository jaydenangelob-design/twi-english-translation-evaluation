# Twi-English Translation Evaluation

A practical evaluation framework for assessing Twi-English AI translations for meaning, grammar, naturalness, register, and overall translation quality.

## Project Overview

This project demonstrates a structured approach to evaluating AI-generated translations between Twi and English.

The goal is to assess whether a translation accurately communicates the original message while remaining grammatically correct, natural, contextually appropriate, and faithful to the intended meaning.

The project is designed as a portfolio demonstration of multilingual AI evaluation skills.

## Evaluation Dimensions

Each translation is evaluated across several dimensions:

- **Meaning Preservation** — Does the translation preserve the meaning of the source text?
- **Grammar** — Is the translated sentence grammatically correct?
- **Naturalness** — Does the translation sound natural to a fluent speaker?
- **Register** — Is the level of formality and tone appropriate?
- **Completeness** — Does the translation preserve all important information?
- **Code-Switching** — Are mixed Twi-English expressions handled appropriately?
- **Overall Quality** — How effective is the translation as a whole?

## Evaluation Scale

Each dimension can be scored using a 1–5 scale:

| Score | Description |
|---|---|
| 5 | Excellent — accurate, natural, and appropriate |
| 4 | Good — minor issues that do not affect the meaning |
| 3 | Acceptable — understandable but contains noticeable issues |
| 2 | Poor — significant problems affect quality |
| 1 | Very Poor — meaning is substantially incorrect or unusable |

## Evaluation Process

For each translation:

1. Read the original source text.
2. Read the AI-generated translation.
3. Compare the meaning of both texts.
4. Check grammar and sentence structure.
5. Evaluate naturalness and fluency.
6. Check tone and register.
7. Identify missing or added information.
8. Record any translation errors.
9. Assign scores using the evaluation criteria.
10. Provide a concise explanation for the final assessment.

## Error Categories

Potential translation errors include:

- Meaning distortion
- Omitted information
- Added information
- Incorrect word choice
- Grammar errors
- Unnatural phrasing
- Incorrect tone or register
- Misinterpretation of context
- Incorrect handling of code-switching

## Portfolio Scope

The examples in this repository are created for educational and portfolio purposes.

They are intended to demonstrate the process of multilingual AI evaluation and should not be considered a production translation benchmark.
