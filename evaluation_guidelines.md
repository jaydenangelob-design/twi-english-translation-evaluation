# Twi-English Translation Evaluation Guidelines

## 1. Purpose

These guidelines provide a consistent method for evaluating AI-generated translations between Twi and English.

The objective is to determine whether a translation accurately communicates the original message while remaining natural, grammatically correct, and appropriate for its context.

## 2. Evaluation Principles

Evaluators should:

- Read the complete source text before judging the translation.
- Compare the translation against the intended meaning of the source.
- Evaluate the translation as a complete message rather than judging isolated words.
- Avoid rewarding literal translations when they sound unnatural or change the meaning.
- Consider context, tone, and register.
- Identify both major and minor translation problems.
- Provide evidence-based evaluation notes.

## 3. Meaning Preservation

Check whether the translation communicates the same core meaning as the source.

Consider:

- Important information
- Actions
- People or objects
- Time
- Quantity
- Negation
- Relationships between ideas

A translation should not receive a high score if important information has been changed, removed, or invented.

## 4. Grammar

Evaluate whether the translated text follows appropriate English or Twi grammatical conventions.

Consider:

- Sentence structure
- Verb usage
